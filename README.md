# Devries Guys Website

A simple hub for the three men's dorm communities in Devries at Trinity Western University:

- 3rd Floor Guys
- 4th Floor X
- 4th Floor Y

## The two files you normally edit

### `data/content.js`
Use this for:
- homepage wording
- RA names and bios
- optional RA photos
- the Verse of the Day list

### `data/events.js`
Use this for dorm nights and rare building-wide events.

Building codes:
- `3` = 3rd Floor Guys
- `4X` = 4th Floor X
- `4Y` = 4th Floor Y
- `ALL` = rare Devries-wide event

The homepage shows **only `ALL` events**. Normal dorm nights stay on their own dorm page.
Past events disappear automatically.

See `EDITING-GUIDE.md` for the easiest editing workflow.
